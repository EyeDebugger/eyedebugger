# Install eyedbg

EyeDebugger is the VS Code side of **eyedbg**, a debugger an AI agent and you share: the agent drives it from the command line, you join the same live session here.

1. Install eyedbg (see the project's README for your platform).
2. Put it on `PATH`, or set **eyedbg.path** in your *user* settings to its absolute path. A workspace can't set it.
3. Click **Check eyedbg**: it shows the version it found, or what is wrong.
