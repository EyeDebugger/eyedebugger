# Start your own session

In `launch.json`, **Add Configuration…** lists the EyeDebugger snippets: join a session, run a Python file or module, build and run a .NET project, or run a built .NET program. Each starts the program under eyedbg and joins it, so an agent can join the same session with `eyedbg sessions` and `eyedbg status`.

When you stop debugging a session you started, EyeDebugger stops it.
