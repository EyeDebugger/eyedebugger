# Start your own session

In `launch.json`, **Add Configuration…** lists the EyeDebugger snippets: join a session, run a Python file or module, build and run a .NET project, or run a built .NET program. Each starts the program under eyedbg as you, with your breakpoints in place before it runs and a .NET build's output in the Debug Console, so an agent can join the same session with `eyedbg sessions` and `eyedbg status`.

Stop ends the session you started; Restart runs the program again.
