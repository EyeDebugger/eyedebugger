# Governance

EyeDebugger is a maintainer-led project.

## Maintainers

| Maintainer | GitHub | Role |
|---|---|---|
| Ijat | [@ijat](https://github.com/ijat) | Lead maintainer |

## Decisions

- Everyday decisions use lazy consensus on issues and pull requests.
- Architecture goes through ADRs ([docs/adr/](docs/adr/)), proposed in a PR and accepted by a
  maintainer.
- With one maintainer, the lead maintainer decides. With more, maintainers seek consensus and the
  lead breaks ties.

## Becoming a maintainer

Sustained quality contributions and reviews, nomination by a maintainer, approval by the
maintainers, then an update to this file and `.github/CODEOWNERS`.

## Code of Conduct

Enforcement is by the maintainers. Report it privately to the project maintainer,
[@ijat](https://github.com/ijat), using the contact details on their GitHub profile.

## Changes to this document

Changes go through a pull request approved by the maintainers.
